## Why

The commissioned T012T hosted proof consumes private12 and refuses the13th lease
observation before it can return the owning proof. The source-accepted report
profile explicitly requires a separate factory amendment rather than omitting
checks, resetting a Decision or silently widening an accepted allocation.

## What Changes

- Propose one trusted qualification-only private38 allocation, selected before
  the first read on the same original operation Decision and retained through
  admission, one proof, exact replay refusal and approved negative controls.
- Preserve ordinary/private12, protected staging/private16, finalization/private12,
  cleanup/private12, all GitHub3/13 or phase-specific limits, original10-second
  operation wall/monotonic window, earliest expiries and role/source/input counts.
- Require actual hosted positive/refusal/timing/cleanup qualification after source
  acceptance. The portable component measurement is not hosted feasibility proof.
- Keep all implementation in openXwallet feature017 tasks.md T012T02-T012T06.
  This packet adds no runtime implementation or operational authority.
