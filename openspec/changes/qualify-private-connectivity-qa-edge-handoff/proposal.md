Status: draft
Kind: governance

## Why

The protected attestor issued a source-only C-01 receipt for the twelve
reviewed Opensoft-Tenant QA edge paths. The active feature reader correctly
refuses the receipt until its exact independently qualified object is
registered. This step lets the coordinator consume that decision without
altering earlier accepted task or rollout evidence.

  approved immutable coordinator history, with exact proof provenance.
- Add only the matching subject key and complete receipt reference to the
  existing closed delegated-attestation register.

  successor definition activation.

the existing protected-base workflow. It leaves the twelve Tenant paths, the
active Feature 043 definition, Q0–Q5 decisions, and source/protected evidence
