## Purpose

Admit the exact Feature 043 QA edge source-scope decision under protected
coordinator evidence custody while preserving the active implementation
definition and existing accepted history.

## ADDED Requirements

### Requirement: Exact source-only receipt registration

The coordinator SHALL register only the protected, independently qualified
immutable receipt matching the exact QA edge source decision and canonical
subject. The existing grant, producer, prior entries, task scope, and active
definition SHALL remain unchanged in the registration candidate.

#### Scenario: The exact receipt is qualified

- **WHEN** the protected reader sees the independently reviewed, reachable receipt using the exact decision subject, valid authority, and verified immutable object
- **THEN** it SHALL admit only the existing C-01 source choice and SHALL grant no target or rollout effect

#### Scenario: A receipt or its authority differs

- **WHEN** commit, path, digest, decision subject, independent review, or authorizing grant differs or is unavailable
- **THEN** the reader SHALL refuse without an alternate reference or history rewrite

### Requirement: Separate evidence and definition controls

The current definition and accepted historical controls SHALL remain active
until the full reviewed successor freeze and independently authenticated
actual E output pass the existing protected and default verification.

#### Scenario: Registration is complete before definition activation

- **WHEN** the exact C-01 source receipt is registered while successor evidence or protection is pending
- **THEN** the existing task definition and rollout decisions SHALL remain in force
